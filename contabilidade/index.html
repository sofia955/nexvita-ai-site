Dúvidas

Perguntas frequentes

Usa o número do escritório?

Pode usar o WhatsApp atual do escritório ou um número novo só para documentos. A conexão é pela API oficial do WhatsApp, da Meta.

Funciona com o meu sistema contábil?

Sim. Os documentos chegam nas pastas que a equipe já usa, prontos para o sistema contábil. Quando o sistema permite integração, também dá para enviar direto para ele.

E se o cliente mandar o documento errado?

A automação confere o tipo de arquivo e o mês. Se tiver dúvida, marca no painel para a equipe olhar, e o cliente é avisado do que ainda falta.

Quanto custa?

Preço de lançamento para os 5 primeiros escritórios: R$ 1.000 para implantar e R$ 490 por mês para manter funcionando, com prazo mínimo de 3 meses. Inclui a coleta de documentos para todos os clientes do escritório, os lembretes e o painel.

Como funciona a garantia?

Antes de começar, medimos com vocês quanto tempo a equipe gasta por mês pedindo e organizando documentos. Se depois de 30 dias rodando a economia for menor que 10 horas por mês, devolvemos os R$ 1.000 da implantação.
